{% docs amount_bucket %}
Сегмент суммы транзакции: `micro`, `small`, `medium`, `large`, `extra_large`.

Границы взяты из распределения `amount`: медиана 47, средний чек 70,
максимум 27 390. Заданы константами, а не квантилями: квантили пришлось бы
считать оконной функцией по всей таблице на каждом запуске.

Возвращает строку, поэтому результат читается в витринах без расшифровки
и проверяется тестом `accepted_values`.
{% enddocs %}


{% docs dbt_date_clickhouse %}
Реализация макросов `dbt_date` под ClickHouse.

Пакет не поддерживает этот адаптер и для неизвестной базы берёт реализацию
по умолчанию — она печатает `to_char` и `date_part`, которых в ClickHouse
нет. Макросы переопределяются через `adapter.dispatch`, и dbt сам выбирает
clickhouse-версию при компиляции.

Отдельно учтено, что коды формата в ClickHouse как в MySQL, а не как
в strftime: полное имя дня недели даёт `%W`, а не `%A`.
{% enddocs %}
